# events/

The event journal. The agent appends small, timestamped records of what it did
or observed (see `../08-events-and-review-loops.md`). A sample journal file lives
alongside this README as a format reference.

*Skeleton — sample format only; real events accrue at runtime.*

Runtime-generated journals are git-ignored (see `.gitignore`); only this README
and `sample-journal.md` are tracked, so normal operation won't dirty the tree.
